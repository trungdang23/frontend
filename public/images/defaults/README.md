# Default Images

Thư mục này dùng để lưu các ảnh mặc định phục vụ frontend Journey.

## Quy ước dùng

- Bỏ file ảnh trực tiếp vào đây hoặc chia thêm thư mục con theo feature như `home/`, `community/`, `maps/`.
- Ảnh trong `public/` sẽ được phục vụ nguyên trạng bởi Vite.
- URL dùng trong app sẽ có dạng `/images/defaults/<ten-file>`.

## Ví dụ

- `public/images/defaults/map-vietnam-aged.jpg`
- URL tương ứng: `/images/defaults/map-vietnam-aged.jpg`
